# Public Folder

This folder contains static assets that will be served at the root of your application.

## Favicon Files

Place your favicon files here:

- `favicon.ico` - Main favicon (16x16, 32x32, or 48x48 pixels)
- `favicon-16x16.png` - 16x16 PNG favicon
- `favicon-32x32.png` - 32x32 PNG favicon
- `apple-touch-icon.png` - 180x180 PNG for iOS devices

### How to Create Favicons

1. **Create your icon image** (recommended: 512x512 or 1024x1024 pixels)
2. **Use an online tool** to generate all sizes:
   - https://realfavicongenerator.net/
   - https://favicon.io/
   - https://www.favicon-generator.org/

3. **Download the generated files** and place them in this `public` folder

4. The files will automatically be available at:
   - `/favicon.ico`
   - `/favicon-16x16.png`
   - `/favicon-32x32.png`
   - `/apple-touch-icon.png`

### Quick Coffee Cup Favicon

If you want a quick coffee-themed favicon, you can:
1. Use an emoji (☕) as a base
2. Convert it using https://favicon.io/favicon-generator/
3. Or create a simple coffee cup icon in your design tool
